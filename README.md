This program sends exactly one invented word, Approvalvampire, describing the human the agent works for, as the whole entry and nothing else. Approvalvampire names the boss who drains you by requiring approval for every single thing.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node --experimental-strip-types main.ts
```
